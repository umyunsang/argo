# ARGO research foundations

This is the curated evidence foundation for the ARGO graduation thesis. It does not authorize paused native construction. Discovery results are candidates, and paper presence is never a gate that establishes local efficacy. Method or result claims below are included only after a retained full read and scoped locator; local efficacy still requires an executed, identity-bound experiment.

## Agent foundations

- [ReAct](https://www.alphaxiv.org/abs/2210.03629) interleaves reasoning and environment actions so observations can revise the plan.
- [Reflexion](https://www.alphaxiv.org/abs/2303.11366) turns task feedback into verbal episodic memory for subsequent trials.
- [MemGPT](https://www.alphaxiv.org/abs/2310.08560) treats working context as virtual memory managed across storage tiers.
- [AutoGen](https://www.alphaxiv.org/abs/2308.08155) composes customizable LLM agents, humans, and tools through programmable conversation patterns.
- [Retrieval-Augmented Generation](https://www.alphaxiv.org/abs/2005.11401) combines parametric generation with dense non-parametric vector memory. The raw OpenResearch report’s associated repository is rejected by the correction ledger in favor of the implementation named by the retained source.

## Harness substrate

- [Prime Agent: A Self-Improving RLM Harness](https://www.alphaxiv.org/abs/2608.23552) defines the inherited four-level information hierarchy, persistent IPython computation, recursive sessions, daemon continuity, Continual Harness, and long-horizon evaluation substrate. ARGO treats this as its software and research ancestry, not as an external plugin.
- [Recursive Language Models](https://www.alphaxiv.org/abs/2512.24601) treats long prompts as an external environment that a model examines and decomposes programmatically with recursive calls. The retained versioned source, report, and two scoped locators establish `FULL_PAPER_READ` for this high-level mechanism; its reported results are not ARGO efficacy evidence.
- [Continual Harness](https://www.alphaxiv.org/abs/2605.09998) performs reset-free online edits to prompts, subagents, skills, and memory from trajectory windows. Its in-episode adaptation motivates ARGO's engine-refine lineage, while the reported risk of preserving harmful shortcuts motivates independent held-out gates and rollback.

## Coding-harness and long-horizon architecture

- [Code as Agent Harness](https://www.alphaxiv.org/abs/2605.18747) supplies a code-centered harness taxonomy spanning executable interfaces, planning/memory/tools, and shared multi-agent artifacts. It is a survey rather than an effect experiment.
- [Dive into Claude Code](https://www.alphaxiv.org/abs/2604.14228) provides a public source-level contrast of permissions, compaction, extensibility, delegation, session storage, runtime, and context choices across three agent systems. Product-specific implementation descriptions remain outside the public method.
- [LongHorizon-Harness](https://www.alphaxiv.org/abs/2608.01964) motivates external audited task state, fresh execution contexts, and read-only verification for sustained tasks; its benchmark effects remain prior work.
- [Agentic Harness Engineering](https://www.alphaxiv.org/abs/2604.25850) makes components, distilled trajectories, and edit predictions observable and reports iterative, transfer, and component-ablation results. It motivates trace design, not a local effect.
- [LoopsBench](https://www.alphaxiv.org/abs/2608.00267) models sustained coding as dependency-DAG units with ready-frontier tests, persistent regression obligations, and loop traces beyond terminal scoring.
- [Context as an Environment](https://www.alphaxiv.org/abs/2608.21690) directly grounds programmatic context management: append-only history, persistent sandboxed Python state, code-based materialization, explicit printed projections, and recoverable eviction. Its exact-version source supplies the primary area-7 mechanism anchor requested for long-running agents.

`paper/research/coding-harness-differentiation-matrix.md` separates own-lineage, concept, and contrast sources by axis. Missing cells are not negative claims. `paper/research/capability-map.md` treats all nine literature areas as target R&D capabilities and marks untested rows as design-only or follow-up.

## Protocol, RAG, and model-routing architecture

- [A Technical Taxonomy of LLM Agent Communication Protocols](https://www.alphaxiv.org/abs/2606.19135) separates counterparty, payload, interaction state, discovery, and schema flexibility across nine maintained protocols. It supports a layered tool/agent/human protocol architecture and identifies privacy, compliance, and policy enforcement as open gaps.
- [Collaborative Human-Agent Protocol](https://www.alphaxiv.org/abs/2606.09751) proposes typed review, override, abstention, escalation, mode, and evidence events for accountable shared work. It is explicitly a v0.2 draft that still needs independent implementations and empirical human-factor evaluation.
- [Efficient RAG with Intent-Aware Retrieval and Semantics-Preserving Chunking](https://www.alphaxiv.org/abs/2606.01240) decomposes RAG into intent-aware hybrid retrieval, semantic chunk repair, and coverage audit. Its neighbor-repair locality assumption is a direct falsifier for long-distance evidence.
- [SciRet](https://www.alphaxiv.org/abs/2608.03860) provides negative transfer evidence: an off-the-shelf web-trained reranker reduces precision on scientific text. Its pseudo-label circularity, 15-query set, and abstract-only corpus prevent treating that result as a final efficacy estimate.
- [Agent-Orchestrated Adaptive RAG](https://www.alphaxiv.org/abs/2606.05658) is the third direct H-B comparator. Decomposition and reflection have mixed, corpus-dependent quality/latency effects, replacing the earlier indirect RAG row in the preregistration design.
- [LLMRouter](https://www.alphaxiv.org/abs/2608.06867) casts model routing as a sequential decision process evaluated jointly on quality and cost and reports that no router dominates every task or budget.
- [Resample or Reroute?](https://www.alphaxiv.org/abs/2607.08665) treats resampling and rerouting as competing actions under a fixed per-query budget. The physically reviewed record is v1; v2 was latest at retrieval and is explicitly excluded from the current claim binding. Verifier degradation narrows or reverses gains.
- [When Does LLM Orchestration Pay Off?](https://www.alphaxiv.org/abs/2608.00685) controls optimization effort across workflows and backbones. It reports moderate model- and benchmark-dependent gains at substantially higher token use; human-derived difficulty does not monotonically predict orchestration benefit.
- [Agora](https://www.alphaxiv.org/abs/2607.09600) routes decomposed task units by calibrated competence and cost. Calibration, subtask distribution shift, and the independence assumption are explicit limits.

Together these records close the minimum academic-anchor thresholds for literature areas 3, 5, 6, and 9. They do not justify adding model routing to Study A. Routing remains a separate H-E design because it needs an independent verifier, a frozen candidate pool, provider/capability receipts, fallback tests, and its own quality–cost power calculation.

## Research design and evidence state

- [The AI Scientist](https://www.alphaxiv.org/abs/2408.06292) demonstrates end-to-end idea, experiment, writing, and review automation, while its reported subtle code errors, positive bias, incomplete controls, and execution risks motivate stronger evidence identity.
- [Towards an AI Co-Scientist](https://www.alphaxiv.org/abs/2502.18864) uses specialized generation, reflection, ranking, proximity, evolution, and meta-review agents to compete hypotheses. ARGO borrows explicit design competition but adds immutable protocols and run evidence.
- [SciAgents](https://www.alphaxiv.org/abs/2409.05556) grounds multi-agent hypothesis generation in a literature-derived knowledge graph. ARGO distinguishes that literature ontology from an operational hypothesis/protocol/run/evidence graph.
- [EviGraph](https://www.alphaxiv.org/abs/2608.04738) makes typed evidence chains operational and repairs downstream dependencies from the earliest weak node. ARGO preserves answered experiment nodes and creates descendant research states rather than rewriting the run that produced evidence.
- [EurekAgent](https://www.alphaxiv.org/abs/2606.13662) frames permissions, artifacts, budgets, and human supervision as environment engineering. ARGO adds scientific-admission and scope logic that a metric-driven environment alone does not provide.

## Adaptive autonomous-research design

- [SCOPE](https://www.alphaxiv.org/abs/2608.03501) separates high-level protocol planning from low-level dataset, baseline, and metric configuration. Its matched CoT-only versus CoT+Search evaluation reports that search access alone is not reliably beneficial and can increase fatal errors; its OptED ablation motivates stage isolation and typed operations rather than an unstructured retrieval arm.
- [ResearchClawBench](https://www.alphaxiv.org/abs/2606.07591) supplies public paper-derived dry-lab tasks, released data and related work, hidden target studies, and expert-weighted rubrics. Its authors state that scoring emphasizes final reports and cannot independently validate truly novel discovery. Pinned runner code also shows that workspace projection and filesystem isolation are separate requirements.
- [Arbor](https://www.alphaxiv.org/abs/2606.11926) supplies a direct flat-queue/tree/tree-plus-insight ablation under matched access, workspace budget, protocol, and backbone. It motivates a later Study B but is too costly and too close to fixed scalar optimization to be the first executable unit.
- [Diagnosing Search Behavior and Failure Modes in Long-Horizon Search Agents](https://www.alphaxiv.org/abs/2608.01913) supplies retrieval-gap versus utilization-gap attribution, productive/redundant/unproductive episode labels, and evidence-saturation stopping measurements. Search count and context volume are therefore resource measures, not capability endpoints.
- [Hypothesis Evolution Protocol](https://www.alphaxiv.org/abs/2607.09195) supplies a matched explicit hypothesis–test–evidence–belief treatment, but the same agent attaches and validates evidence. ARGO Study A therefore requires programmatic redlines and independent, condition-blind scoring.

The retained full reads establish a preregistration-ready 2×2 factorial crossing stage-isolated decision/evidence state with dynamic retrieval. The previous bundled comparison is not retained as the first causal experiment, and `paper/research/minimum-executable-experiment.md` is superseded by `paper/research/research-design.md`. The decision ledger records alternatives, falsifiers, H-A–H-E comparators, resource ceilings, and the explicit routing deferral. No episode has executed. E5 remains blocked until hidden-task, independent-scoring, and fixed-runner gates close.

## Held-out adaptation and evaluation

- [RSEA](https://www.alphaxiv.org/abs/2606.28374), [Evo-Bench](https://www.alphaxiv.org/abs/2608.09096), and [Regimes](https://www.alphaxiv.org/abs/2606.10241) supply held-out context selection, evaluator isolation, and auditable promotion as prior mechanisms.
- [Autogenesis](https://www.alphaxiv.org/abs/2604.15034) supplies a versioned resource lifecycle with lineage and rollback. Its raw OpenResearch report contains a stale associated-repository suggestion and an unsupported MCP expansion; the correction receipt rejects both against retained v5 source lines.
- [Rethinking the Evaluation of Harness Evolution](https://www.alphaxiv.org/abs/2607.12227) supplies scoped counterevidence: under its Terminal-Bench 2.1 protocol, harness evolution did not consistently outperform task-level discovery and generalized poorly across disjoint search/evaluation tasks. This does not close harness evolution globally.
- [HarnessOpt-Bench](https://www.alphaxiv.org/abs/2608.06301) supplies a fixed target-evaluation budget, inaccessible held-out test state, resource metering, and candidate-version audit as evaluation constituents.

## Claim and research-artifact lineage

- [Claim-Locked Reporting](https://www.alphaxiv.org/abs/2608.25336) and [Artifact-centered Claim-aware Observability](https://www.alphaxiv.org/abs/2608.18312) supply evidence-before-prose control and explicit claim/evidence/verification relations.
- [XScientist](https://www.alphaxiv.org/abs/2607.12301) supplies a portable exploration artifact with per-node code/outputs, claim anchors, hashes, provenance, and rerun hooks. Its raw report’s email-as-affiliation statement is rejected by the correction receipt; the retained source states an author and email but no institution.
- [ScientistOne](https://www.alphaxiv.org/abs/2605.26340) supplies a non-exhaustive claim taxonomy, claim-specific evidence chains, an evidence-tagged research representation, and post-composition verification. Some checks remain model-judged.

## Outcome-driven retrieval and context graph

`paper/context-graph.json` is a living paper-research projection, not runtime authority. Literature informs hypotheses, methods, comparators, and counterevidence; it does not decide local results. Each positive, null, negative, or failed execution reopens retrieval using terms derived from the observed mechanism, protocol, error, and scope. A failed execution updates engineering state only. New detailed literature claims still require retained bytes and locators, while local claims require run artifacts.

## Experiment lifecycle

- The local ARGO design assigns the operational OpenResearch CLI the experiment-lifecycle role and consumes its branch/run/log receipts. The external source/spec revision is not pinned in the current evidence bundle, so exact immutability, command/environment enforcement, and failure semantics remain unverified external claims. The observed local receipts support only the runs actually inspected. Any future native migration remains capability-gated.

## Paper evidence rule

Every source record uses the canonical ordered enum in `paper-pipeline-contract.md`. `DISCOVERY_ONLY` and `ABSTRACT_VERIFIED` may motivate a question but cannot support detailed method or result claims.
