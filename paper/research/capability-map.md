## Cycle-selection rationale

### R-CYCLE-01 — select this thesis cycle's validation surface

- **Selection item:** validate the smallest cross-area path needed to test whether structured research state changes experimental-design quality.
- **Alternatives considered:** (A) test all capabilities together—high relevance but causally unidentified and infeasible; (B) test only deterministic validators—feasible but does not measure agent research behavior; (C) test a connected slice spanning sandbox, evaluator, observability, graph state, decision procedure, retrieval, evidence ledger, and stopping—selected.
- **Evidence:** SCOPE `2608.03501` (`FULL_PAPER_READ`), ResearchClawBench `2606.07591` (`FULL_PAPER_READ`), Arbor `2606.11926` (`FULL_PAPER_READ`), search diagnosis `2608.01913` (`FULL_PAPER_READ`), HEP `2607.09195` (`FULL_PAPER_READ`).
- **Criteria and weights:** prerequisite centrality 0.30; feasibility without native runtime work 0.25; measurable prior effect/failure 0.20; thesis-question relevance 0.15; token/time cost 0.10.
- **Expected effect:** a complete causal path for Study A can be instrumented without claiming that untested target capabilities already exist.
- **Risk:** excluded capabilities may interact with Study A and limit generality.
- **Falsifier:** if the selected slice cannot enforce hidden evidence, matched budgets, or condition-blind scoring without native runtime changes, it moves to design-only and E5 remains blocked.

### R-ROUTING-DEFER — keep the model fixed in Study A

- **Selection item:** dynamic model routing is a target capability but not a Study A factor.
- **Alternatives considered:** dynamic routing versus fixed model in the same factorial; routing-only preliminary study; fixed identical model for all Study A conditions—selected.
- **Evidence:** RLM `2512.24601` (`FULL_PAPER_READ`) supports recursive decomposition but does not by itself establish provider-aware routing; direct routing anchors are not yet full-read.
- **Reasoning:** varying model assignment would confound structured-state and retrieval effects and multiply the condition count from four to at least eight before routing MDE and cost are known.
- **Risk:** results apply to one model revision and do not establish routing benefit.
- **Falsifier:** routing becomes a current-cycle factor only if area-9 studies show a large, task-conditioned effect detectable under the available episode ceiling and a matched routing benchmark can be released.

## Current-cycle validation set

The current cycle validates 10 connected functions: sandbox, evaluator, observability, context graph, operational procedure, normative constraints/decision heuristics, retrieval pipeline, literature/citation validation, claim–evidence ledger, preregistration/deterministic validation, and iterative stopping. These are one connected treatment-and-measurement path; success does not imply the remaining target capabilities are implemented or effective.

## Open capability questions

- Personalized memory, MCP semantics, vector-database backends, framework-specific development stack, persistent-daemon provenance, and all model-routing mechanisms lack complete anchor/effect evidence.
- Capabilities requiring native runtime changes remain design-only by default. Configuration, skill, workflow, protocol, and external test-harness work may proceed on the reference base.
