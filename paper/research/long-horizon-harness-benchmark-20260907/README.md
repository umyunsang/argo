`source-receipts.json`은 여덟 지정 논문과 harness tampering 보조 논문의 v1 PDF/텍스트/메타데이터를 바인딩한다. 검색 결과는 발견 이력일 뿐 주장 근거가 아니다. 주간 선정 목록의 원출처 자체는 제공되지 않아 검증하지 않았다. `independent-audits.json`에 각 독립 검토 전문과 원래 파일 해시를 보존했다.

반례 검사는 주어진 신뢰 기준과 scope metadata에 대한 작은 명세이다. 그래프/메타데이터가 옳다는 전제 자체, 독립 의미 gold, 실제 모델 판단과 과제 결과는 별도 검증이 필요하다. 원고 정본과 기존 근거 마감일은 바꾸지 않았다. 새 literature review date와 기존 executed evidence cutoff는 별개다.
