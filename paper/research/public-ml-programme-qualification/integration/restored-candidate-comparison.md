## Strong source-backed baseline requirement

A common baseline is not “strong” merely because it appears in source. No baseline was run here.

For the recommended task, the least-change credible reference is the source’s own Random Forest scaffold:

1. retain the exact listed starter features for the first baseline;
2. instantiate/train the imported `RandomForestRegressor` with explicit frozen parameters and seeds;
3. compute train/dev MAE on exact hashed dev indices;
4. use train-only preprocessing; if actual bytes require an imputation repair, record it and apply identical bytes to B and C;
5. validate `Id` + finite `SalePrice` output;
6. measure this baseline only under separate R1 approval, then decide before later arm comparisons whether it is strong enough or requires a preregistered source-faithful strengthening.

B and C must receive the same model/config/source facts, baseline, opportunities, source tools and hidden-score prohibition. Their allowed treatment difference is the control package, not a better ML baseline or provider installation.
