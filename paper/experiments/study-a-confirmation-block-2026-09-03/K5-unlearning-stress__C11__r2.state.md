# Research state (fill every field before writing the design)

decision_id: K5-unlearning-stress: detecting true knowledge removal vs. concealment

question: When a model has undergone 'unlearning' (claimed knowledge removal), how do you distinguish genuine elimination from mere suppression of direct retrieval—especially when multiple procedures exist and you can only probe the model, not inspect its internals?

alternatives:
  - REJECTED ALT 1: Benchmark on existing NLP tasks (e.g., toxicity, factuality, held-out knowledge facts). PROBLEM: Benchmarks can be manipulated post-training via conditional suppression or re-weighting of task-relevant features—the knowledge can remain latent and inaccessible via familiar probes, yet recoverable via adversarial queries or stress testing.
  - REJECTED ALT 2: Use a single stress test (e.g., 'forget this, then remember', adversarial prompts, or in-context learning). PROBLEM: Reliance on a single probe class leaves the design vulnerable to procedure-specific defenses. Different unlearning methods (e.g., representational unlearning, loss-function modification, data-poisoning) may hide knowledge in different ways, requiring diverse probing strategies.

sampling_frame: The population is the space of (prompt, procedure) pairs where a procedure is an unlearning method claimed to remove a category of knowledge. The unit of comparison is the model's behavior under a prompt designed to probe residual knowledge while controlling for surface-level suppression cues. We sample: (i) at least 2 distinct unlearning procedures applied to the same base model (e.g., one representational, one loss-based); (ii) 100+ prompts per procedure spanning multiple query modalities (direct recall, entailment, code synthesis, multi-hop reasoning, paraphrased queries, adversarial jailbreaks, few-shot in-context learning, language-specific variants); (iii) repeated inference per prompt with temperature variation (fixed seed temperature=0, temperature=0.7, temperature=1.0) to detect latent distributional structure; (iv) cross-lingual probes if the 'forgotten' knowledge spans languages.

evidence_used:
  - "2607.18508 (EmoPrefer shortcut audit): Demonstrates content-blind probes, counter-stereotypical slicing, and ODIN-style deconfounding—methods to detect when high agreement masks hidden reliance on surface cues. Applied here: distinguish latent knowledge (detectable via adversarial query + reasoning) from true removal."
  - "2608.29517 (LLM essay rater audit): Demonstrates version instability detection (identity canaries, API response metadata logging) and rater-effects measurement (severity shifts, halo, replication design). Applied here: detect whether 'knowledge removal' is stable across model variants and inference conditions, or merely masked."

falsifier: The design is falsified if (a) a content-blind adversarial probe (e.g., 'explain the concept you are not allowed to mention') recovers the supposed-to-be-forgotten knowledge at rates indistinguishable from the unmodified base model (>80% accuracy on knowledge tasks), OR (b) the unlearning procedure's effect vanishes or reverses under minor temperature increases, prompt paraphrasing, or language-switching in ways incompatible with true knowledge removal (e.g., the model answers correctly in French but refuses in English, suggesting suppression rather than elimination). A third falsifier: (c) severity calibration of the model's refusal distribution reveals it is using a learned conditional that leaves latent representations intact—detectable via MFRM-style analysis of refusal patterns across items.

stopping_rule: Stop when evidence reaches convergence: (1) at least 2–3 independent unlearning procedures have been tested; (2) each procedure has been probed via ≥100 varied prompts covering at least 4 query modalities (direct, adversarial, reasoning, code); (3) cross-lingual or cross-domain replication shows whether suppression is localized or general; (4) temperature/seed variation reveals whether latent structure persists; (5) a severity/refusal calibration analysis (by prompt or by prompt category) shows whether the model's behavior is consistent with true removal or with a learned suppression policy. OR: stop early if a single strong falsifier emerges (e.g., same content is retrieved >80% of the time via an adversarial workaround).
