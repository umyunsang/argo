## Evidence rules used here

Canonical source-read levels are ordered: `DISCOVERY_ONLY < ABSTRACT_VERIFIED < FULL_PAPER_READ < PRIMARY_SPEC_OR_CODE < REPRODUCED_EXPERIMENT`. Claim-type admissibility is orthogonal rather than globally substitutable: a reproduced run cannot establish a license, code cannot establish efficacy, and a full paper cannot establish repository behavior. Admission is claim-conditioned:

| Claim type | Minimum admissible local basis |
|---|---|
| Literature method or reported result | Retained full source with a reviewed exact locator |
| Software identity or behavior | Pinned primary specification/code plus byte-derived or behavioral fixtures |
| License, ancestry, or redistribution | Authoritative provider/license records bound to exact bytes and revision |
| Local efficacy | Immutable run artifacts under the exact matched protocol and estimand |
| External outcome | Identity-bound external-oracle receipt, kept separate from local inference |

- **`DISCOVERY_ONLY` rows support no paper claim.** They are locally retrieved title/abstract candidates only. `full_read_candidate` is a screening priority, not a read receipt.
- **`NONE` is a matrix-only gap marker.** It means a named source was not retrieved and must fail closed.
- `PRIMARY_SPEC_OR_CODE` on an internal ARGO document supports only the statement that the design contract says something. It is not independent support for usefulness, originality, or implemented behavior.
- Structured reports and versioned source receipts are retained for all forty-three focused reads: forty-two source archives and one versioned PDF/text fallback. `paper/sources/claim-locators.json` retains 74 exact locators. All pass embedded-excerpt hash and scoped semantic review; the 11 adaptive-round5 and 22 round-7 locators were re-derived from exact-version TeX after full-paper reads. Future detailed claims require new scoped locators; retention alone upgrades no claim.
- No row contains a reproduced ARGO harness-efficacy experiment. Reported results from prior papers are prior-work claims only.
- Local source code establishes implementation and ancestry facts only. It does not establish performance or safety.
- External software identity is separate from an internal ARGO designation. The ARGO documents that assign OpenResearch a role support only that local design fact; the unpinned external OpenResearch spec/code remains `NONE`.

4. **Fill the largest conceptual and empirical gaps.** Personalized-memory forgetting, evaluator calibration, risk-tiered approval, review burden, override quality, and independent relevance annotation remain unvalidated.
5. **Do not promote design contracts into results.** Prospective tests must compare stock Prime Agent with the smallest ARGO slice under matched tasks, models, data, commands, budgets, evaluators, and human-authority boundaries.
6. **Earn contribution tags.** `RE_DERIVED` needs an ARGO revalidation; `MODIFIED` needs a base diff and matched evaluation; `ORIGINAL_ARGO` needs source archaeology, native code, ablations, and evidence; `EXTERNAL_ORACLE` facts must remain explicitly external.
