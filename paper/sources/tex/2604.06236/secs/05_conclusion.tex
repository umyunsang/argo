\section{Conclusion}
\label{sec:conclusion}
% ==================================================================

The file drawer was a rational adaptation to a world in which
retrieving failure was more expensive than repeating it. Large
language models have inverted this cost structure. Failure data that
was once too costly to retrieve and too voluminous to digest can now
be searched, synthesized, and applied at scale. The published
scientific record is positively biased, and the systems learning
from it inherit that bias. The technology to change this now exists.
What remains is the harder problem of defining what a meaningful
failure publication looks like in each field, building the
infrastructure to support it, and creating the institutional
incentives that make contributing to it worthwhile.
