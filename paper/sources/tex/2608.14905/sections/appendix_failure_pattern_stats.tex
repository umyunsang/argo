

\section{Failure Pattern Statistics}
\label{sec:failure_pattern_hits}

The following tables present the detailed failure pattern statistics across
the 800 agent trajectories analysed (8 models $\times$ 100 tasks). A pattern
counts as a HIT when the trajectory analysis presents the failure as established,
and as PARTIAL when it is raised but qualified; HIT\% is the share of the 800
analyses in which the pattern is an established failure.
Table \ref{tab:appendix_total_hits} shows the overall totals per pattern.
Table \ref{tab:appendix_hit_matrix} provides the breakdown of the HITs across
the evaluated models, using the abbreviations in Table \ref{tab:model_legend}.
Table \ref{tab:failure_matrix} visualizes the cross-classification.
