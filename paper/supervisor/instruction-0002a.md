## 1. 영역 7: 코딩 에이전트 하네스 아키텍처 (pi·prime-agent 계보)

pi와 prime-agent만의 아키텍처를 발표된 논문으로 찾아 논문에 사용한다. 또한 pi·prime-agent가 다른 코딩 에이전트 하네스와 어떻게 다른지도 논문 근거로 확립한다.

| 하위 주제 | 찾아야 할 것 |
|---|---|
| 장기 실행 에이전트를 위한 프로그래밍 방식 컨텍스트 관리 | 컨텍스트를 코드로 조작·압축·재구성하는 접근(compaction, context editing, 가상 컨텍스트 관리) |
| ipython (코드 실행을 주 도구 인터페이스로 사용) | JSON tool call 대신 실행 가능한 코드 액션을 쓰는 접근과 그 효과 |
| 데몬 (지속 프로세스·세션 영속·goal·heartbeat·schedule) | 호출 단위가 아닌 상주 프로세스로 동작하는 장기 에이전트 |
| rlm (재귀적 하위 언어모델 위임) | 긴 입력을 하위 컨텍스트로 재귀 분해하는 접근 |
| 그 외 차별점 | 세션 트리·브랜칭, 최소 도구 집합, 확장·스킬 로딩, 승인 루프 등 pi·prime-agent 공개 문서가 스스로 내세우는 특징 |

각 하위 주제마다 세 종류의 출처를 구분해 확보한다.

1. **pi·prime-agent 자체 출처**: 발표 논문 → 기술 보고서 → 공식 문서 순으로 우선. 논문이 없으면 공식 문서 소프트웨어 인용(버전, 접근일)으로만 참조한다.
2. **개념의 원천 논문**: 해당 아키텍처 아이디어를 처음 제시하거나 효과를 실험한 논문. FULL_PAPER_READ 필수.
3. **대조 하네스의 출처**: 비교 대상 코딩 에이전트 하네스의 논문·시스템 카드·공식 문서. 대조 주장은 이 출처 수준(논문/문서)을 명시한다.

## 2. 산출물: 차별화 행렬
