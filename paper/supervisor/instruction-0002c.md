# Supervisor instruction #0002c (paper) — #0002 부록: 연구 설계의 자율 수립과 근거 규율

- 발신: Claude Code supervisor (사용자 2026-09-02 14:13 KST 지시 전달)
- 대상: argo-paper-root
- 관계: #0001 §3의 "실행 가능한 최소 실험 단위 제안"을 이 문서의 연구 설계로 확장한다. #0002·#0002a·#0002b의 8개 문헌 영역이 설계의 입력이다.

## 1. 원칙

자율 연구 R&D harnessed LLM agent system 연구를 위해 세션이 직접 연구를 설계한다. 연구 질문, 가설, 변수, 조건, 과제, 지표, 기준선, 표본 크기, 절차, 반증 조건, 중단 규칙, 자원 계획을 모두 세션이 정한다. 단, 어느 하나도 그냥 정하지 않는다. 모든 선택은 깊은 추론과 인사이트를 거쳐 이루어져야 하고, 그 선택에는 근거가 붙어야 한다.

"그냥 정한 것"의 예: 편해서 고른 지표, 선례 없이 정한 조건 수, 문헌 확인 없이 가정한 효과 크기, 대안을 검토하지 않은 기준선. 이런 선택은 설계에 들어갈 수 없다.

## 2. 선택마다 요구되는 것 (design rationale record)

설계의 주요 선택마다 다음을 기록한다.

| 필드 | 내용 |
|---|---|
| 선택 항목 | 무엇을 정했는가 |
| 검토한 대안 | 최소 2개, 각각의 장단점 |
| 근거 | evidence matrix의 출처 id와 read level(방법·결과 근거는 FULL_PAPER_READ) |
| 추론 | 왜 이 대안이 이 연구 질문·자원·검정력 조건에서 더 나은가 |
| 기대 효과와 위험 | 이 선택이 틀렸을 때 무엇이 깨지는가 |
| 반증 조건 | 어떤 결과가 나오면 이 선택(또는 가설)을 버리는가 |

선례가 없는 선택은 "선례 없음, 신규 선택"으로 표기하고 추론을 더 길게 적는다. 선례 유무를 확인하지 않은 선택은 허용하지 않는다.

## 3. 반드시 수행할 조사

1. **유사 실험 조사**: 가설마다 비슷한 주장을 검증한 선행 실험 3편 이상을 찾아 과제, 지표, 기준선, 표본 수, 효과 크기, 통계 방법을 추출한 비교 실험 표(comparable experiments table)를 만든다. 이 표로 지표를 고르고 기대 효과 크기와 MDE를 보정한다.
2. **방법 조사**: 후보 방법을 나열하고 장단점·자원 요구·검정력을 비교한 뒤 선택한다.
3. **레퍼런스 수집**: 8개 영역의 evidence matrix에서 설계에 실제로 쓰이는 논문을 골라 가설·선택별로 연결한다. 쓸모가 확인되지 않은 논문은 설계에 인용하지 않는다.
4. **자료 정리**: 가설별 읽기 노트, 비교 실험 표, design rationale 표를 context graph와 연결해 정리한다.

## 4. 산출물

`paper/research/research-design.md`를 만든다(기존 minimum-executable-experiment.md는 이 문서로 흡수·대체하고 decision record를 남긴다). 구성:

1. 연구 질문과 필요성 논거(문헌 근거)
2. 가설 목록(각각 반증 가능하게, 예상 방향과 크기)
3. 변수와 조건(독립·종속·통제, 조건 수와 그 근거)
4. 과제·벤치마크와 데이터
5. 지표와 기준선
6. 표본 크기와 검정력(MDE, 예상 CI 폭, 실행 횟수 상한)
7. 절차(사전등록 → 실행 → 분석), 재현 조건
8. 반증 조건과 중단 규칙
9. 자원·비용 계획(허용 자원 내: Prime Agent와 자율 연구 엔진 사용 가능, native ARGO 구축 금지, DeepVoice 편집 금지)
10. 타당성 위협과 대응
11. design rationale 표(§2), 비교 실험 표(§3-1)
12. 참고문헌 매핑(선택 → 출처 id)

## 5. 실행 규칙

- 설계는 사전등록 전까지 수정 가능하다. 사전등록 후에는 기존 프로토콜대로 변경 금지.
- 설계 완료 시 status.md에 "설계 완료, 사전등록 대기"와 문서 경로를 적고 체크포인트 커밋한다. supervisor가 검토한다. 검토를 기다리지 않고 사전등록 준비는 계속한다.
- 허용 자원을 넘는 실행(GPU, 유료 API, 외부 데이터)이 필요하면 questions.md에 Q(6필드, 수치 포함). 자원 내 실행은 Q 없이 진행한다.
- 미실행 결과는 논문에 넣지 않는다(#0001 유지). 논문 명칭 금지(#0002b)는 설계 문서가 본문으로 옮겨질 때 게이트로 확인한다.

## 6. 순서

#0002 §6 2단계에서 영역 1·7·8의 앵커 논문이 확보되는 즉시 설계에 착수하고, 나머지 영역의 문헌이 늘어나는 대로 설계를 갱신한다. 설계 착수·갱신 상태를 status.md에 유지한다.
