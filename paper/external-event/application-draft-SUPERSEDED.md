## 프로젝트명

**ARGO — 자기 계측기를 검증하는 AI 네이티브 R&D 에이전트**

## 한 줄 요약

연구의 모든 단계에 에이전트를 넣되, **그 에이전트가 낸 결과를 믿어도 되는지까지 스스로 검증하는**
연구 하네스.

## 해결하려는 문제

자율 연구 에이전트는 이미 가설을 세우고 실험을 돌리고 보고서를 쓴다. 정작 비어 있는 것은
**"이 결과를 믿어도 되는가"** 를 판정하는 층이다. 우리는 이것을 추측이 아니라 실측으로 확인했다.

| 관측 | 값 | 의미 |
|---|---|---|
| 근거 미검출을 음성으로 처리했을 때 뒤집힌 판정 | **38.9%** | 검색 실패가 과학적 음성으로 위장된다 |
| 채점 방법 변경만으로 생긴 변화 ÷ 검출하려던 효과 | **2.3배** | 계측기가 효과보다 크게 움직인다 |
| 채점 방법 분산 ÷ 측정 대상 분산 | **1.48배** | 부호가 뒤집혀 상수 보정 불가 |
| 도구 감사가 잡은 무증상 결함 | **3종** | 통과하던 검사가 실제로는 아무것도 안 보고 있었다 |

계측기를 검증하지 않으면 자율 연구는 **틀린 결과를 빠르게 대량 생산**한다.

## 아이디어 — 책임 계층(accountability layer)

ARGO는 기존 에이전트 하네스 위에 네 가지를 얹는다.

1. **여섯 필드 결정 기록** — 질문·대안·근거·결정·예상효과와 위험·**반증 조건**을 결과 확인 전에 고정한다.
2. **등급이 붙은 근거 그래프** — 요약 열람 / 전문 정독 / 직접 실행을 구분해 저장하고, 투영
   다이제스트로 그래프가 조용히 어긋나는 것을 막는다.
3. **반증 시험을 통과한 계측기** — 측정 도구는 일부러 망가뜨린 입력에서 **반드시 실패해야** 한다.
   실패하지 않으면 그 도구는 근거를 만들 자격이 없다.
4. **생성자·평가자 분리** — 산출물을 만든 에이전트가 그것을 채점하지 않는다.

## 프로토타입 구성

기존 공개 연구에서 검증된 축을 벤치마킹해 조합하고, 그 위에 책임 계층을 얹는다.

| 설계 축 | 계승·채택 | ARGO가 더한 것 |
|---|---|---|
| 실행 기반 | 코드를 행동으로 삼고 문맥을 변수로 다루는 실행 기반을 계승 | 실행 단위마다 결정 기록 식별자를 붙여 사후에 어떤 판단이 그 실행을 낳았는지 되짚게 한다 |
| 상태 지속 | 세션을 넘어 살아남는 상태 계층을 계승 | 상태 갱신을 근거 등급과 함께 기록해, 검증되지 않은 학습이 조용히 정책이 되는 것을 막는다 |
| 위임 | 독립 작업의 병렬 위임을 계승 | 생성자와 평가자를 분리해 같은 에이전트가 자기 산출물을 채점하지 못하게 한다 |
| 실험 생애주기 | 불변 노드와 고정 실행 계약을 계승 | 노드마다 사전등록과 반증 조건을 요구해, 결과를 본 뒤 판정 기준이 바뀌지 못하게 한다 |
| 검색 | 의미 검색을 근거 수집 경로로 채택 | 검색 재현율을 채점 전에 측정한다. 본 연구에서 근거를 못 찾은 결과를 음성으로 처리했을 때 실제로 오판이 발생했다 |
| 지식 표현 | 문맥 그래프를 지식 표현으로 채택 | 노드마다 근거 등급과 허용성 판정을 붙이고, 투영 다이제스트로 그래프가 소리 없이 어긋나지 못하게 한다 |
| 루프 설계 | 관찰 조건부 절차와 반성 루프를 계승 | 루프의 각 회차가 여섯 필드 결정 기록을 남기고, 반증 조건을 결과 확인 전에 고정한다 |
| 평가 | 분리된 평가와 보류 보호를 채택 | 측정 도구 자체를 반증 시험에 건다. 도구 감사가 실제로 세 종류의 결함을 잡아냈다 |

## 시연 계획 (본선 19시간)

본선에서 처음 만들지 않는다. 사전에 동작하는 골격을 세우고, 본선에서는 **연구 과제 하나를 다섯 단계로
완주**시켜 보인다.

1. 연구 공백 선택 → 2. 문헌 검색 + 전문 정독 → 3. 여섯 필드 결정 기록 →
4. 실행 가능한 단위 실행 → 5. 근거 그래프 갱신 + 재현 검증

**심사위원이 직접 확인할 수 있는 것:** 임의의 결론 하나를 골라 "왜 이렇게 판단했는가"를 물으면,
결정 기록·근거 등급·실행 영수증까지 역추적된다. 또한 계측기를 일부러 망가뜨리면 시스템이 **결과를
내지 않고 멈춘다.**

## 차별점

대부분의 연구 에이전트는 **더 많이 만드는 것**을 목표로 한다. ARGO는 **틀린 것을 걸러내는 것**을
목표로 한다. 그리고 그 효과를 주장이 아니라 **실행된 측정으로** 제시한다.

## 기대 효과

- 자율 연구 결과에 대한 **감사 가능성** 확보
- 검색 실패가 과학적 음성으로 위장되는 오류의 **사전 차단**
- 연구 과정 자체가 재현 가능한 **영수증으로 남음**
