- 완료 범위: 용어 검색 → 핵심 4개 문헌의 관련 본문 독해 → 적용/한계 종합 → 원문·해시 보존.

## 1. 결론

**현시점 학술 글쓰기에 본 과제에 적용할 검증된 보편적 SOTA는 없다.** 이 검토에서도 한국어 학위논문·과학적 정확성·독자 이해를 하나의 공통 지표로 비교해 우승한 기법은 확인하지 못했다. 아래 선정은 최신성 순위나 효능 보장이 아니라, 원문을 확인할 수 있고 현재 원고에 적용 가능한 원칙의 선택이다. 선택 문헌은 편집 지침과 수사적 분석이며 한국어 ARGO 논문에 대한 비교실험이 아니다. [W1–W4]

권고 문체는 **“독자가 추론을 따라갈 수 있는, 근거 범위에 맞춘 연구 논증”**이다. 논문 연구 → 검증된 통합 설계 → ARGO 구현 → NAIS라는 연구 프로그램은 유지하되, 뒤 단계의 목표를 이미 달성한 성과로 소급하지 않는다. 현재 완료된 계측·평가 도구 점검은 그 자체의 결과로 기술하고, 아직 인정된 시스템 효능 결과가 없는 상태와 구별한다. 효능 미입증을 무효과 입증으로 바꾸지도 않는다.

## 2. 기법명과 귀속

용어 검색에는 `web.run`을 사용했다. 검색·추출 출력이 불안정한 경우 공식 페이지 직접 읽기와 보조 검색을 사용했다. 다음 자료는 **4개 핵심 문헌과 별개의 출처 확인**이다.

| 사용자 용어 | 확인 및 한계 | 이번 개정 판단 |
|---|---|---|
| power writing / 파워 라이팅 | 이름만으로 사용자가 뜻한 저자·책·절차를 특정하지 못했다. 교육용 동명 표현을 특정 학술 이론의 정의나 원조로 채택하지 않았다. | 명명된 방법을 강제하지 않는다. 정확한 저작이 제공되면 별도 검토한다. |
| high-five writing / 하이파이브 글쓰기 | 유사 명칭 교육 자료가 검색되지만, 한국어 연구논문의 검증된 단일 표준이나 사용자가 뜻한 원전을 특정하지 못했다. | 다섯 요소를 형식적으로 채우는 규칙이나 효능 근거로 쓰지 않는다. 원전 미확인은 방법의 부재를 뜻하지 않는다. |
| Churchill PERP / PREP | Toastmasters 공식 2021년 글의 항목 5는 PREP를 Point–Reason–Example–Point로 명시한다. 이는 해당 순서의 **사용 증거**이지 발명자·기원 증거가 아니다. PERP의 뜻과 처칠 귀속은 확인하지 못했다. [T1] | **Churchill attribution 불충분.** “처칠이 만든 PREP/PERP”라고 쓰지 않는다. PERP를 확정적으로 오타 처리하지도 않는다. |

국제 처칠 협회의 「The Scaffolding of Rhetoric」 소개문은 1897년 글을 소개하고 어휘·리듬·논증의 축적·유추를 논한다. 보존한 것은 소개·인용문이지 처칠 원문 전체가 아니다. 그 페이지의 원문 PDF 링크는 회수 시 404였다. 원문 전체를 대조했다고 주장하지 않으며, 소개문에 PREP가 보이지 않는다는 사실만으로 기원 부재를 증명하지 않는다. **확보 자료로 귀속을 정당화할 수 없으므로 사용하지 않는다는 판단**이다. 페이지의 1970-01-01 표시도 원저작 연도로 쓰지 않는다. [T2]

PREP의 예시는 과학적 증거와 같지 않다. 논문에는 자료가 주장을 지지하는 이유와 추론의 한계가 필요하다. 아래 문단 원칙은 특정 기법들을 혼합한 이론이 아니라 이 개정을 위한 편집적 종합이다. [W1, W4]

## 4. 일관된 한국어 논문 문체

### 문단의 논증

**주장 → 증거 → 증거가 주장을 지지하는 이유 → 적용 한계**가 필요할 때 드러나게 쓴다. 네 문장 강제 규칙이나 모든 문단의 고정 순서는 아니다. 정의·전환 문단에 억지로 자료나 면책문을 붙이지 않는다. 한계를 매 문단 반복하지 말고 실제 추론이 발생하는 곳과 논의 장에서 정확히 한정한다. [W1, W4]

- 주장: 무엇을 설명하거나 제안하는가. “중요하다”보다 해결하려는 구체적 문제를 쓴다.
- 증거: 직접 읽은 선행연구, 완료된 관찰, 설계 전제를 구별한다. 선행연구의 성공을 ARGO의 성공으로 바꾸지 않는다.
- 연결 이유: 왜 이 자료가 이 결론을 지지하는지 쓴다. 인용의 존재만으로 추론이 성립하지 않는다.
- 한계: 어떤 조건에서 성립하며 무엇을 검증하지 않았는지 적는다. 모호한 겸양 표현으로 대체하지 않는다.

### 표현 강도

| 상태 | 권고 표현 | 피할 표현 |
|---|---|---|
| 문헌에서 확인 | “해당 연구는 … 조건에서 …을 보고했다.” | 인용만 붙여 “ARGO도 …을 보장한다.” |
| 잠정 설계 | “…을 분리하는 구조를 제안한다.” / “후속 비교 방법으로 잠정 설정했다.” | “최적 방법을 확립했다.” |
| 완료된 도구 점검 | “평가 도구의 … 동작을 지정된 점검 조건에서 확인했다.” | “전체 연구 에이전트의 신뢰성을 입증했다.” |
| 미평가 효능 | “…에 미치는 영향은 후속 통합 평가의 대상이다.” | “효과가 있다.” 또는 “효과가 없다.” |
| 향후 구현·적용 | “검증된 설계를 구현으로 연결하고, 이후 NAIS 적용을 평가한다.” | “통합 구현과 실환경 적용을 완료했다.” |

설계와 관찰을 정확히 구별하면 “가능할 수 있을 것으로 생각된다” 같은 중첩 완곡어는 불필요하다. 확정된 사실까지 흐리게 쓰지 않는다. “최초·모든·증명·보장”은 실제 근거가 해당 강도를 지지할 때만 쓴다. [W4]

### 실질적 연구 내용을 보존

서론의 장기 연구 과제, 지속 문맥, 외부 근거, 실험 설계와 수정이라는 문제의식은 보존한다. 관련 연구·정의·설계 대안·메커니즘을 삭제하고 승인 상태나 점검 목록만 남기는 개정은 하지 않는다. 원고 도입부 표본의 “정량적으로 입증”, “통계적으로 증명”, “학술적 선례 확립”은 실제 결과 확보 여부를 통합 담당자가 확인한 뒤 낮추거나 범위를 제한한다. 이 lane은 원고 전체를 감사하거나 결과 수치를 재판정한 것이 아니다.

**본문에서는 코딩 에이전트 벤더 이름과 내부 관리 경로를 배제한다.** 필요한 공개 자료 식별자는 정식 인용·자료 가용성 설명으로 처리하고, 로컬 경로·해시·작업 상태는 편집 및 증거 관리 문서에만 둔다. 기존 학술 인용을 문체 수정 과정에서 임의로 떼어내지 않는다.

다음은 새 효능을 주장하지 않는 표현 예시다. 선행연구에 의존하는 주변 문장은 통합 담당자가 해당 연구의 직접 근거와 연결해야 한다.

> 본 연구는 장기 연구 과제에서 근거의 선택과 설계 변경 사이의 관계를 추적할 수 있는 연구 에이전트 구조를 제안한다. 제안 구조는 연구 과정의 수정과 에이전트 자체의 수정을 구별하며, 각 변경의 이유와 평가 조건을 연결하는 것을 목표로 한다. 이러한 구분이 연구 성과에 미치는 영향은 후속 통합 평가에서 검증할 가설이다.
>
> 현재 완료된 평가는 개별 평가 도구의 동작 점검에 한정된다. 이 점검은 후속 실험에 사용할 도구의 지정 동작을 확인한다는 의의가 있으나, 전체 시스템의 연구 수행 능력이나 제안 구조의 효능을 평가한 결과는 아니다. 따라서 본 논문은 잠정 설계와 현재 확보된 점검 결과를 구별하여 기술하고, 통합 평가를 거쳐 구현과 후속 적용으로 이어질 연구 절차를 제시한다.

### 캡션 — 제작은 별도 담당

캡션은 **무엇을 나타내는가 → 어떻게 읽는가 → 어디까지 주장하는가**를 설명한다. 제안 구조도와 결과 그림을 구별하고 실제 화살표·선 종류·약어만 설명한다. 계측 점검 그림에는 전체 시스템 평가가 아니라는 범위를 명시한다. 원자료 없는 수치·향상·완료 상태를 추가하지 않는다. [W3, W4]

예시: “그림 X. 제안 연구 에이전트의 정보 흐름. 각 연결은 근거 선택, 설계 변경, 평가 결과 사이의 전달 관계를 나타낸다. 본 도식은 연구 설계의 개념적 표현이며, 통합 구현이나 시스템 효능의 검증 결과를 나타내지 않는다.” 실제 그림에 존재하는 관계에 맞춰 조정한다. IEEE 흑백 규격이나 폰트 수치를 이 문헌으로 새로 정당화하지 않는다.

## 6. editorial-methods용 BibTeX 후보 3개

원고의 과학적 연구 배경 참고문헌에 자동 추가하지 않는다. DOI는 첫째·셋째 논문에서 확인했고 W2에 확인되지 않은 DOI를 부여하지 않았다. W4는 개정 연도를 추정하지 말고 기관·페이지 제목·접근일 2026-09-05로 기록한다.

## 7. 인계

1. 연구 문제·기술 개념·설계 이유·관련 연구를 유지하고, 미완료 성과의 표현만 근거 범위에 맞춘다.
2. 결과와 주장에 직접 근거·추론 한계를 연결한다. 수치·평가 단위 재판정은 해당 lane에 맡긴다.
3. 문체 문헌은 editorial-methods에 둔다. 본문을 벤더·내부 경로·작업 상태 보고로 바꾸지 않는다.
4. 캡션 검토사항만 도식 담당자에게 전달한다. 도식 제작·규격·렌더링 성공은 이 lane의 판정 대상이 아니다.

진행 기록: 관련 원문 독해와 문체 메모 완료. 원고 수정·문서 렌더링·코드 시험·외부 게시·유료 작업·중첩 위임 없음. 네 문헌으로 편집 판단을 구성했으며 한국어 문체 개선 효과를 측정했다고 주장하지 않는다.
