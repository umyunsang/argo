# FAIRNESS primary-source archive and reading ledger

## 상태와 보존의 의미

- 공개 서지 결정: **출판된 R2/R3/R4만 공개 원고에 적용**한다. R1 원문·메타데이터는 비공개 편집 이력으로만 보존하며, 다운로드·해시 기록은 공개 인용 승인이 아니다. 비용·정보 매칭은 본 연구의 제안 설계로 서술한다.
- 열람일: **2026-09-05 KST**. 수집 시각·원래 URL·응답 URL·HTTP 상태·bytes·SHA256은 `retrieval-manifest.json`의 파일별 기록이 권위다.
- 이 디렉터리는 후속 요청에 따라 다시 내려받은 원문이다. 이전 턴의 일시적 웹 응답 bytes가 보존되어 있었다거나 이번 파일과 bit-for-bit 같았다고 주장하지 않는다.
- 공식 arXiv/NeurIPS/JMLR 호스트에서 PDF 전체 4개, 서지 HTML 4개, 공식 BibTeX 3개를 보존했다. `web.run` 공식 URL 재조회도 시행했으나 빈 응답은 검증 근거에서 제외했다. 보존 파일의 근거는 성공한 공식 HTTPS 응답과 그 bytes에서 다시 읽은 본문이다.
- `*.txt`는 `pdftotext 26.03.0 -layout`으로 PDF 전체에서 만든 파생물이다. **전체 추출 또는 해시 생성은 전체 열람·정독·실험 재현을 뜻하지 않는다.** 줄 번호는 LF 기준 1-based이며 form-feed는 페이지 경계다.
- 읽기 수준: 네 문헌 모두 `selected_passages_read`. `full_text_read`, `replicated`, `independently_verified`로 승격하지 않는다. 검색 일치 행은 탐색에만 사용했고 아래 선택 구간과 구별한다.
- 계획/진행: 원문 수집 완료 → 선택 구간 재열람 완료 → 한국어 적용 문단·서지 보강 완료 → 파일 해시·인용 키 정합성 확인. root의 공유 계획과 원고에는 쓰지 않았다.

## 출판 상태·서지 추적

- R1: arXiv 2407.01502v1, 2024-07-01 제출. `R1-arxiv-metadata.html`의 citation 메타데이터와 v1 제출 이력을 확인했다. arXiv DOI `10.48550/arXiv.2407.01502`는 식별자이며 최종 저널판 DOI로 바꿔 부르지 않는다. 최종 TMLR판과의 일치·최종 저널 서지는 미확인이다.
- R2: NeurIPS 2024, volume 37, pp.50528–50652, DOI `10.52202/079017-1601`. 공식 `R2-publisher.bib`를 그대로 보존했다.
- R3: NeurIPS 2023 Datasets and Benchmarks, volume 36, pp.46595–46623, DOI `10.52202/075280-2020`. 공식 `R3-publisher.bib`를 그대로 보존했다. 이전 노트의 DOI 미확인을 이번 증거로 보완했다.
- R4: JMLR 22(164):1–20, 2021. 공식 `R4-publisher.bib`를 그대로 보존했다. 이 응답에 DOI가 없으므로 꾸며 넣지 않았다.
- `fairness-application.bib`: 공개 원고 적용용 **R2/R3/R4 3개 레코드만** 포함한다. R2/R3의 키는 기존 문안과 맞추고 제목의 대소문자 보호용 중괄호를 추가했다. 나머지 서지 필드는 공식 레코드에서 가져왔다. R1의 v1 레코드는 비공개 `../fairness-reader-review.md` §7에만 남겼다.

## 적용 경계

핵심 산출물은 `../fairness-reader-review.md` §6의 한국어 문단이다. 정보대칭을 위한 그래프/평면형 자료 비교, 정상 기능을 유지한 comparator, 자원 상한과 실제 소비의 구분, 증거 단계별 주장 제한은 **문헌을 ARGO에 적용한 권고**다. 선행연구가 이 ARGO 설계를 직접 검증했다고 쓰지 않는다. 논문의 전체 성과를 재현하거나 현재 ARGO raw artifact를 감사하지 않았다.

`SHA256SUMS`는 이 폴더 파일들의 보존 상태 점검용이며 그 자체는 읽기나 주장 타당성의 증거가 아니다. 파일을 변경하면 해당 합계도 갱신해야 한다. 원문과 파생물을 외부 공개·재배포하지 않았다.
