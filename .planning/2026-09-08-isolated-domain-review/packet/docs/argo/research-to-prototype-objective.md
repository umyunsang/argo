# 논문 연구에서 검증된 ARGO 프로토타입으로

2026-09-08 사용자 목적 재확인. 이 문서는 내부 연구·제품 방향이며 논문 본문이 아니다.

최종 목적은 **장기 자율연구 하네스의 역할·연결·제어 설계를 선행연구와 비교 실험으로 선택하고, 그 근거를 논문에 정리한 뒤 2026 NAIS AI Hackathon의 ARGO 프로토타입으로 구현하는 것**이다. 문헌 정리나 논문 파일 생성만으로 이 연쇄가 완료되지 않는다.

pi, Prime Agent, OpenResearch CLI, Exa, context graph, loop engineering, graph engineering은 구현의 벤치마킹 대상이다. 각각을 어떤 책임으로 연결하고, 어떤 대안을 비교하며, 실패와 비용을 어떻게 반영할지가 연구 설계에 포함된다. 모든 요소를 넣는 것을 성공 기준으로 삼지 않는다. 검증 결과에 따라 채택·수정·축소한 설계가 프로토타입을 결정한다.

논문은 실제 읽은 학술 원문의 기제, 실험으로 검증한 설계 선택, 성능·비용·실패·한계를 기술한다. 내부 도구명·제품명·해커톤 계획을 학술 기여로 옮기지 않는다. 정확한 학술 서지정보는 보존하고, 공개 preprint와 동료심사 게재 논문을 구분한다. 상세 출판 경계는 `paper/manuscript/AGENTS.md`를 따른다.

SOTA는 목표다. 동일 과제·모델·자료·예산·선택 규칙·평가 조건의 직접 비교가 없으면 달성했다고 주장하지 않는다. graph나 복잡한 설계의 우위를 전제하지 않으며, 단순한 설계가 이기거나 결과가 불확실할 가능성을 유지한다.

연구용 연결 설계와 검증은 진행한다. 이 목적 재확인은 native construction 재개, 이미 동결된 실험의 변경, 출판·제출 완료를 뜻하지 않는다. 기존 승인과 완료된 준비를 보존하며, 현재 실행 여부는 요약 문구보다 task-bound 최신 receipt를 확인한다.
