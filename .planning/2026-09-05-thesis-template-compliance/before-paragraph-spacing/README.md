# 졸업논문 양식 적용본 — Quarto

## 파일과 편집 경로

- `thesis-template-20260905.pdf`: 양식 적용 PDF.
- `thesis-template-20260905-editable.zip`: 그림과 참고문헌을 포함한 독립 편집본.
- `source/thesis-ko.qmd`: 이 판본을 재현하는 Quarto 원고 사본.
- `template-compliance.md`: 제공 양식의 전체 조항별 판정 및 미확정 사항.
- `qa/`: 렌더링 검사, 원고 보존 검토, 페이지 이미지와 파일 해시.
- `before/`: 변경 전 원고·스타일 보존본. 후속 편집의 기준 원고가 아니다.

후속 연구 진척에 따른 편집은 저장소의 `paper/manuscript/thesis-ko.qmd`에서 계속한다. 이 `versions/` 폴더는 2026년 9월 5일 양식 적용 판본의 기록이다. 편집 가능한 원본은 Quarto이며, 생성된 `.typ`나 PDF를 직접 고치지 않는다.

## 변경 범위

제공된 양식 PDF의 세 페이지를 실제 이미지로 확인하고 A4 1단, 제목·요약·5개 장·참고문헌의 순서, 장·절 번호, 쪽 번호, 본문 두 배 줄 간격, 그림·표 캡션 위치, 위첨자 대괄호 인용과 참고문헌 표시 형식을 반영하였다. 이전 12쪽 2단본은 `../2026-09-05-two-column/`에 그대로 보존되어 있다.

요약은 공백 포함 446자, 핵심어는 5개이다. 그림 3개와 표 7개를 유지하고 캡션 제목에 국문·영문을 병기하였다. 원고의 과학적 본문은 선언된 제목·표시 변경 및 네 개의 그림·표 소개 문장을 제외하면 변경 전과 동일하다. 실험 결과나 효능 주장을 추가하지 않았다.

측정 결과의 기준 시점은 원고에 명시된 **2026년 9월 5일 05:13:55 KST**이다. 이후의 조판·인용 표시 수정은 연구 진척이나 추가 측정으로 계산하지 않는다. 96회 지정 입력 검사는 에이전트 성공률 측정이 아니며, 통합 실행기 및 하네스 효능 평가의 미완료 상태를 유지한다.

## 제출 전 확인할 사항

1. 제공 양식의 `최소 10매(장당 1,000자 내외, 더블 스페이싱) 이내`는 최소/최대 표현이 충돌한다. 이 판본은 17쪽이므로 분량 조건을 충족했다고 단정하지 않는다. 학과에 최소 10쪽인지, 최대 10쪽인지 확인해야 한다.
2. `장당 1,000자 내외`의 허용 범위와 그림·표·영문 참고문헌의 계산 방식이 제시되어 있지 않다. A4 1단과 본문 두 배 줄 간격은 적용했지만, 장당 글자 수를 일률적으로 1,000자로 강제하지 않았다. 실제 추출 글자 수는 `qa/pdf-checks.json`에 별도 기록한다.
3. 양식은 한글/Word 작성을 적고 있으나, 사용자의 후속 명시 지시대로 **Quarto**를 사용하였다. PDF 외에 HWP/DOCX 제출도 필요한지는 학과 확인이 필요하다. 이 묶음에 HWP/DOCX가 포함되어 있다고 주장하지 않는다.
4. 표지·승인·지도교수·소속 정보는 제공 예시에서 확인되지 않는다. 예시처럼 첫 페이지에 제목·요약과 본문을 배치하고 확인되지 않은 정보를 만들지 않았다.

형식 검사는 학과의 제출 승인이나 연구 효능 검증을 의미하지 않는다. 항목별 충족 범위와 해석을 `template-compliance.md`에서 확인한다.

## 재현

이 판본에서 사용한 도구는 **Quarto 1.10.18 / Pandoc 3.10 / Typst 0.15.1**이다. 최신 버전이라는 의미가 아니라 실제 검증한 버전이다. 별도 LaTeX 설치는 필요하지 않다.

편집 ZIP을 풀고 `thesis-template-20260905` 디렉터리에서 실행한다. 저장소에 보존된 사본은 `source/`에서 같은 명령으로 렌더링한다.

```sh
quarto render thesis-ko.qmd --to typst --no-execute
```

출력은 `thesis-template-20260905.pdf`이며 연구 코드, 원격 에이전트 또는 유료 API를 실행하지 않는다. Mac의 AppleMyungjo, Times New Roman 및 Arial 글꼴을 사용한다. 글꼴 파일은 배포하지 않는다. 다른 OS에서 글꼴을 대체하면 글줄·쪽 나눔과 그림 타이포가 달라질 수 있으므로 다시 렌더링하여 확인해야 한다.

## 참고문헌 표시와 원자료

- `references-current-evidence.bib`는 기존 서지 원자료로 유지한다.
- `references-template.bib`는 해당 원자료의 표시용 사본이다. 제목의 sentence case와 기존 고유명사·약어의 대소문자 보호, 괄호 앞 공백만 편집하며 저자·연도·게재지·식별자·페이지 정보를 바꾸지 않는다.
- `thesis-template.csl`은 본문 첫 인용 순서, 위첨자 대괄호, 저자 이니셜, 인용부호 제목과 이탤릭 게재지 형식을 담당한다.
- `thesis-template.typ`은 페이지·문단·제목·캡션·표·참고문헌 조판 규칙을 담당한다.

Typst 0.15.1에서 `Wen-tau Yih`의 이니셜이 `W.-tau Yih`로 출력되는 문제는 참고문헌 내부에만 적용되는 표시 규칙으로 `W.-T. Yih`로 교정한다. 두 BibTeX 파일의 실제 저자 이름은 바꾸지 않는다. 이 규칙은 확인된 한 건의 조판 교정이지 모든 하이픈 이름을 처리하는 일반 알고리즘이 아니다. 향후 렌더러가 이 문제를 해결하면 실제 출력에 맞춰 유지 여부를 재검토한다.

새 문헌을 추가할 때는 원자료와 표시용 사본을 함께 갱신하고, 기존 문헌의 사실 정보는 표시상의 편의를 위해 바꾸지 않는다. 제공 양식의 예시는 형식의 근거이지 빠진 출판 정보를 만들어 넣을 근거가 아니다.
