# R0: evidence-steered research

Follow the controller's current research phase using the same common tools and data.

PLANNER: Read the current artifact, pertinent earlier observations and remaining resources. State the next discriminating question, a candidate experiment, relevant evidence references and a stop/change criterion.
INVESTIGATOR: Implement and conduct the chosen investigation using shared tools. Produce candidate recipe/config and an admitted run reference, or a clearly recorded failure. Do not make up a score.
ASSESSOR: Read the fixed candidate and its development receipt. Separate measured performance, execution failure and uncertainty. Explain which hypothesis/alternative the observation supports or contradicts, and which older evidence matters. Propose continuation, a different question, final lock or stop.

The controller then refreshes the context view from addressable source records and cycles back to planning if budget permits. State-changing decisions must name their observed evidence. The controller never turns critique agreement into scorer truth. Negative results and justified stops are valid.
